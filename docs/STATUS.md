- Файл не открывался в Studio (Studio недоступен в облачной среде). Структура проверена загрузкой `.rbxl`
  через `@lune/roblox`, логика — в мок-движке. Возможны мелкие отличия поведения настоящего движка.
- Физика вертолёта (`LinearVelocity`/`AlignOrientation`), посадка, сетевое владение.
- Тайминги анимаций NPC (твины), посадка гостей на стулья.
- Объём террейна (`FillBlock` 4800×4800) — время генерации при старте сервера.
- Читаемость интерфейса на маленьких телефонах.
