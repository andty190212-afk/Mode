# Запуск и тестирование в Roblox Studio

## 1. Открыть проект
1. Установите Roblox Studio (https://create.roblox.com).
2. Откройте `dist/RestaurantIslandTycoon.rbxl` (двойной щелчок или `File → Open from File`).
   Альтернатива: распакуйте `dist/RestaurantIslandTycoon.rbxlx.zip` и откройте `.rbxlx`.
3. В окне Explorer должны быть:
   - `Workspace.Map.Islands.Island1…Island8`, `Workspace.Map.SkyLounge`, `Workspace.Map.OceanPreview`
   - `ReplicatedStorage.Shared` (модули), `ReplicatedStorage.Assets` (модели), `ReplicatedStorage.Remotes`
   - `ServerScriptService.Main` + папка `Services`
   - `ServerStorage.RestaurantTiers.Tier1…Tier5`
   - `StarterPlayer.StarterPlayerScripts.ClientMain` + папка `Controllers`
   - `StarterGui.Loading`

> `OceanPreview` — полупрозрачная плоскость «воды» для режима редактирования. При запуске сервер
> создаёт настоящий террейн-океан, лагуны и горы, а `OceanPreview` удаляет.

## 2. Сохранения в Studio
Чтобы прогресс сохранялся при тесте в Studio: `Game Settings → Security → Enable Studio Access to API Services`
(доступно после первой публикации места). Без этого игра работает, но использует временные данные
(в Output будет предупреждение `DataStore unavailable`).

## 3. Одиночный тест (F5 / Play)
1. Появитесь на небесной площадке → откроется окно «Выбор острова».
2. «Открыть ресторан» → вы на своём острове. Откройте «Профессии» и выберите профессию.
   В Studio Шеф-повар и Директор доступны без покупки (`Config.StudioGrantGamePasses = true`).
3. Через ~10 секунд начнут приходить гости.

### Проверка каждой профессии
| Профессия | Что сделать |
|---|---|
| Повар | Подойдите к табло «🧾 ЗАКАЗЫ» на кухне (или кнопка «🍳 Готовить заказ» внизу) → пройдите мини-игры (Пробел/кнопка). Готовое блюдо появится на «🛎️ РАЗДАЧА». Без официанта гости заказывают через планшет и забирают еду сами. |
| Официант | `E` у стола «Принять заказ» → у раздачи «Забрать блюда» → у стола «Подать блюда» → после ухода гостей «Убрать стол». Без повара работает медленная автокухня. |
| Бар | Повар или официант: `E` у бара «Приготовить напиток» или кнопка «🍹 Сделать напиток». Иначе — автомат напитков. |
| Шеф-повар | На кухне появляется NPC «Су-шеф». Меню «Персонал» → обучение. В меню появляются фирменные блюда шефа. |
| Директор | «Персонал» → «Нанять» повара/официанта/бармена → наблюдайте, как NPC работают сами; зарплаты списываются раз в минуту. |

### Остальные системы
- **Продукты**: кнопка «Продукты» слева или холодильник «📦 СКЛАД» на кухне. «⚡ Докупить всё для меню».
- **Меню и цены**: «Ресторан» → вкладка «Меню и цены».
- **Стройка**: кнопка «Стройка» слева → выберите предмет → ЛКМ поставить, `R` повернуть, `Q` выйти.
  «✋ Переместить / удалить» — режим редактирования.
- **Рейтинг**: «Улучшения» → «Рейтинг ★». Для быстрого теста прогрессии в Studio во вкладке
  «Ресторан → Обзор» есть кнопка «🧪 Studio: ускорить тест» (+100 гостей, +$250 000 в бюджет, репутация,
  критик). Кнопка и запрос работают **только в Studio** (`RunService:IsStudio()`), на живых серверах отключены.
  Оборудование и красоту всё равно нужно купить — это проверяет магазин и стройку.
  Там же кнопки **★ … ★★★★★** — мгновенно переключают уровень ресторана (здание, меню, гости, мебель),
  тоже только в Studio.
- **Вертолёт**: нужен ресторан 3★ и «Вертолётная площадка» (Стройка → Остров → Транспорт).
  Меню «Вертолёт» → купить → «Вызвать» → `E` «Сесть за штурвал». W/S, A/D, Пробел/E вверх, Shift/Q вниз.
- **Барьер**: меню «Барьер» → «Включить барьер».

## 4. Тест на двух и более игроках
`Test → Clients and Servers → Local Server, 2 Players → Start`.
- Игрок 1 открывает ресторан, выбирает профессию, «Команда» → «Пригласить».
- Игрок 2 видит всплывающее приглашение → «Принять» → выбирает только свободную профессию.
- Проверьте: игрок 2 не может выбрать занятую должность; не может вывести деньги; тратить бюджет
  может только после «Друг: может тратить» у владельца.
- Барьер: игрок 3 (без доступа) не может войти на остров — его переносит обратно.

## 5. Чек-лист перед публикацией
- [ ] Output без ошибок (красных строк) при запуске сервера и клиента.
- [ ] Гости приходят, садятся, заказывают, едят, платят, уходят.
- [ ] Каждая мини-игра проходится на ПК и в эмуляторе телефона (`Test → Device`).
- [ ] Интерфейс читается на телефоне (эмулятор iPhone/Android) и планшете.
- [ ] Повышение до 2★ меняет здание.
- [ ] Вертолёт: взлёт, полёт, посадка на ПК и с экранными кнопками.
- [ ] Сохранение: выйти и зайти снова — ресторан, мебель, звёзды восстановлены.
- [ ] Покупки Robux проверены тестовыми покупками в Studio после настройки ID.

## 6. Автоматические проверки (без Studio)
```bash
cargo install lune --locked
lune run tools/check.luau src              # компиляция всех скриптов
lune run tools/build_place.luau            # сборка build/*.rbxl(x)
lune run tools/test/server_test.luau       # сценарий сервера (131 проверка)
lune run tools/test/client_test.luau       # интерфейс и мини-игры (67 проверок)
lune run tools/test/balance_sim.luau 10    # баланс экономики
./tools/package.sh                         # всё сразу + dist/
```
