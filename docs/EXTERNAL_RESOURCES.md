# Внешние ресурсы, требующие настройки

Игра полностью работоспособна без внешних ассетов: все модели построены из деталей, иконки интерфейса — эмодзи,
звук клика — встроенный (`rbxasset://`). Ниже — то, что стоит настроить для финального качества.

## Звуки (Config.Sounds)
Найдите звуки в Creator Store (вкладка Audio, фильтр «Free»), скопируйте ID и впишите как `"rbxassetid://<ID>"`.
Пустая строка = звук не проигрывается (без ошибок).

| Ключ | Где используется | Что подобрать |
|---|---|---|
| `Click` | клики интерфейса | уже задан встроенный звук |
| `Buy` | покупки, размещение | уже задан встроенный звук |
| `Error` | ошибки/предупреждения | уже задан встроенный звук |
| `Cash` | чаевые, оплата | кассовый аппарат / монеты |
| `Upgrade` | уровень, звезда | короткий «успех» |
| `Cooking` | старт мини-игры | шипение сковороды |
| `Door` | (резерв) | дверной колокольчик |
| `Crowd` | (резерв) | гул ресторана |
| `Helicopter` | полёт (цикл) | вертолёт, loop |
| `Ocean` | фон мира (цикл) | шум волн |
| `Birds` | фон (цикл) | тропические птицы |
| `Music` | фоновая музыка | лёгкая lounge/tropical музыка |

Используйте только аудио с разрешением на использование в вашем опыте (публичные звуки Creator Store
или загруженные вами).

## Необязательные улучшения
- **Иконки/картинки**: можно заменить эмодзи в интерфейсе на свои изображения (`ImageLabel`).
- **Анимации NPC**: NPC сделаны лёгкими (без Humanoid) ради производительности; при желании можно добавить
  покачивание/анимации на клиенте.
- **Меши**: модели мебели и зданий можно заменить на MeshPart, сохранив имена ключевых деталей
  (`PassCounter`, `BarCounter`, `OrderBoard`, `Fridge`, `HostStand`, `CookSpot1..3`, `BarSpot1`, `WaiterSpot1..3`,
  `BuildingSign`, `Roof`, `Ceiling`, `Origin`) — сервер ищет их по имени.
- **Миниатюры и иконка игры** для страницы опыта.
